# Intern Engineering Foundation

## Project Overview

This project is a simple Python-based intern profile application created as part of the Git and Version Control assignment.

The application stores basic intern information and displays the profile in the terminal.

## Intern Profile

The profile contains:

- Intern Name
- Role
- Department
- Skills
